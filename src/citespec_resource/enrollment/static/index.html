接下来会发生什么

  1. 管理员核对申请和公钥；如信息不足，状态会变为“需要补充材料”。
  2. 批准后系统自动创建受限账号、workspace 和 root 管理的登录公钥。
  3. 状态变为“已批准/已开通”后，使用邮件或指南中的地址完成 SSH 配置。
  4. GPU 使用仍然由你自助申请和排队，普通使用不需要每次人工审批。
